Modulul 0

Dezvoltarea aplicațiilor în C++

Pentru a construi și executa un program scris în limbajul C++, parcurgem o serie de pași bine definiți:

1. Editare Sursă

Scrierea instrucțiunilor folosind un editor de text. Fișierul rezultat are extensia .cpp.

2. Compilare

Compilatorul verifică sintaxa codului. Dacă nu există erori, codul este tradus în cod mașină (obiect).

3. Executare

Rularea programului rezultat de către sistemul de operare pentru a obține rezultatele.

4. Testare & Depanare

Verificarea corectitudinii cu diverse seturi de date și izolarea/corectarea eventualelor erori logice.

Modulul 1

Vocabularul, Structura și Tipurile de date

Setul de caractere & Identificatori

Vocabularul cuprinde litere (A-Z, a-z), cifre (0-9), caractere speciale (%, *, #, &) și separatori (spațiu, virgulă, punct și virgulă).

Identificatorii: Sunt nume folosite pentru variabile, constante sau funcții. Ei trebuie să înceapă obligatoriu cu o literă sau caracterul underscore (_), continuând cu litere, cifre sau underscore.

Constantele pot fi literale (ex: 123, 012 (baza 8, prefix 0), 0x1A (baza 16, prefix 0x), 'A', "șir") sau simbolice (folosind cuvântul-cheie const).

typedef int INTREG; // Crearea unui tip definit de utilizator
INTREG a, b; // Variabile de tipul personalizat INTREG
Modulul 2

Operatori C++ în detaliu

1. Operatori Aritmetici

Efectuează operații de calcul matematic:

  • + , - , * : Adunare, scădere, înmulțire.
  • / : Împărțire întreagă (dacă ambii operanzi sunt întregi: 13 / 3 => 4) sau reală (13.0 / 3 => 4.33).
  • % : Restul împărțirii întregi (exclusiv pentru întregi: 13 % 3 => 1).
  • ++ , -- : Incrementare/decrementare unară. ++a (prefixat, mărește valoarea înainte de evaluare) sau a++ (postfixat, folosește valoarea curentă în expresie, apoi mărește).

2. Conversie Explicită (Cast)

Sintaxă: (tip_data)operand. Util pentru a forța împărțirea reală a doi întregi:

int a = 9, b = 6;
float ma = (float)(a + b) / 2; // Valoarea va fi 7.5, în loc de 7

3. Operatori Relaționali & Logici

Valoarea de adevăr în C++ este reprezentată prin 0 pentru Fals și orice valoare diferită de 0 pentru Adevărat (implicit 1).

  • Relaționali: >, >=, <, <=, == (egalitate), != (diferit). Ex: 6 == 6 => 1 (Adevărat).
  • Logici: && (ȘI logic - adevărat doar dacă ambii sunt adevărați), || (SAU logic - adevărat dacă cel puțin unul e adevărat), ! (negație).

4. Operatori pe Biți (Bitwise)

Efectuează operații direct pe biții numerelor întregi:

  • & ȘI pe biți | | SAU pe biți | ^ XOR (SAU exclusiv)
  • ~ Negație pe biți (unar)
  • << Deplasare la stânga (înmulțire cu $2^n$)
  • >> Deplasare la dreapta (împărțire întreagă cu $2^n$)

5. Atribuire & Operatorul Condițional

Atribuiri compuse: +=, -=, *=, /=, %= (ex: a += 5 înseamnă a = a + 5).

Operatorul Condițional (Ternar): singurul operator cu 3 operanzi în C++.

Sintaxă: expresie1 ? expresie2 : expresie3 Funcționare:

Se evaluează expresie1. Dacă este adevărată, se returnează expresie2. Altfel, se execută și se returnează expresie3.

Exemplu: min = (a < b) ? a : b;

Modulul 3

Instrucțiuni de control: Structuri Alternative

1. Instrucțiunea if (Alternativa Simplă)

Sintaxă: 
if (expresie) {
    instructiune1;
} else {
    instructiune2;
}
Execuție:

Se evaluează expresie. Dacă valoarea sa este adevărată (diferită de zero), se execută instructiune1. Altfel, dacă există ramura else, se execută instructiune2.

⚠️ Capcană: Nu adăugați punct și virgulă după paranteza rotundă a if-ului: if(conditie);. Blocul următor s-ar executa necondiționat deoarece compilatorul consideră că instrucțiunea din if este cea vidă.
Exemplu: 
if (n % 2 == 0) {
    cout << "Par";
} else {
    cout << "Impar";
}

2. Instrucțiunea switch (Alternativa Generalizată)

Sintaxă: 
switch (expresie_intreg) {
    case valoare1:
        instructiune1;
        [break;]
    case valoare2:
        instructiune2;
        [break;]
    default:
        instructiune_default;
}
Execuție:

Se evaluează expresia (care trebuie să returneze un tip întreg sau caracter). Se compară cu valorile din fiecare etichetă case. Atenție! Dacă lipsește instrucțiunea break;, execuția continuă secvențial prin următoarele etichete case!

Modulul 4

Instrucțiuni repetitive (Bucle)

1. Instrucțiunea while (Test Inițial)

Sintaxă: 
while (expresie) {
    instructiune;
}

Se testează condiția înainte de fiecare iterație. Dacă expresia este inițial falsă (0), corpul buclei nu se execută niciodată.

2. Instrucțiunea do-while (Test Final)

Sintaxă: 
do {
    instructiune;
} while (expresie);

💡 Pro-Tip: Garantează întotdeauna cel puțin o executare a corpului buclei, deoarece condiția este evaluată după rularea blocului de instrucțiuni.

3. Instrucțiunea for (Cu Pas/Contor)

Sintaxă: 
for (exp_init; exp_test; exp_inc) {
    instructiune;
}

Se execută expresia de inițializare, apoi se verifică testul. După fiecare iterație se execută expresia de incrementare, reevaluând testul.
